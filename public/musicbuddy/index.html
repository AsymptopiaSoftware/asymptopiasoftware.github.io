About this release

Music Buddy is a product of agentic assisted coding, built on approximately twenty years of earlier sight-reading trainer work: MusicTeX flashcards, the Java SightReadingTrainer, d3SRT, and Cosmic Harmony. The current web version uses browser MIDI, speech synthesis, and guided journeys. No Python service is required.
