About this release

Version 0.1 preserves the focused Music Buddy exercise: spoken chord names, MIDI validation, journeys, transposition, and live feedback. This app uses browser Web MIDI; no Python, account, or server is required. Audio speech uses the browser's installed voices. Browsers without MIDI support can view the journeys but cannot validate a hardware keyboard.
